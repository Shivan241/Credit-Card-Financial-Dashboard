# Credit Card Financial Dashboard

A Credit Card Financial Dashboard project designed to analyze customer spending, transactions, revenue, and key financial metrics using SQL and Power BI.
/mnt/data/customer_dashboard.png

## 📊 Project Overview

This project presents interactive Power BI dashboards for analyzing credit card customer and transaction data.

The dashboard provides insights into:

- Total Revenue
- Total Transaction Amount
- Transaction Count
- Total Interest
- Customer Income
- Customer Job
- Education Level
- Age Group
- Salary Group
- Marital Status
- Top 5 States
- Expenditure Type
- Card Category
- Transaction Method
- Quarterly Revenue and Transaction Count

## 📈 Customer Report

The Customer Report analyzes customer demographics and financial performance.

- **Total Income:** 577M
